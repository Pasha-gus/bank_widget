# Проект "Виджет для банка"

## Описание:
IT-отдел крупного банка делает новую фичу для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента. Пользователь выбирает тип файла с ,которым будет работать программа, и фильтры которые необходимо применить.

## Установка: 
Чтобы скачать проект необходимо зайти на страницу github по сылке bank_widget https://github.com/Pasha-gus/bank_widget/pull/8 и клонировать репозиторий

## Использование: 
Чтобы пользоваться программой запустите модуль main в корневой папке проекта и следуйте указанием выводящимся в комаедной строке.
1. Выбеоите тип файла который необходимо считывать
2. Выберите статус интерисующих вас операций
3. Выберите нужнно ли сортировать по дате
    - Выберите нужно сортировать по возрастанию даты или по убыванию даты
4. Выберите нужно ли выводить только рублевые транзакции
5. Выберите нужно ли выводить транзакции по какому то конкретному слову
Программа отсортирует все по вашим требованиям и выведет список транзакций

## Документация:
Проект пользуется сайтом Exchange Rates Data API: https://apilayer.com/exchangerates_data-api для конвертации валют.
