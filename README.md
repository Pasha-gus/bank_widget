# Проект "Виджет для банка"

## Описание:
IT-отдел крупного банка делает новую фичу для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента. Пользователь выбирает тип файла с ,которым будет работать программа, и фильтры которые необходимо применить.

## Установка: 
Чтобы скачать проект необходимо зайти на страницу github по сылке bank_widget https://github.com/Pasha-gus/bank_widget/pull/1 и загрузить необходимые файлы

## Использование: 
Чтобы пользоваться программой запустите модуль main в корневой папке проекта и следуйте указанием выводящимся в комаедной строке
